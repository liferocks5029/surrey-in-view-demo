# Surrey in view

Independent interactive development-map demonstration by 5th Avenue Partners. Not an official City of Surrey service. Public-source examples and approximate building massing; see the map source notes for coverage, dates, licences and limitations.

The map includes a **Manage** link to an interactive staff demonstration. Drafts, previews, publication and history stay in the visitor's browser; they cannot change the shared GitHub website. It is not password protected. Real shared publishing and Microsoft/password authentication require a production backend. Browser storage is not a backup; export a draft to keep it.

This repository contains public demo assets only. It does not contain a staff backend, credentials, private drafts, research documents or private development history.

Data includes information licensed under the Open Government Licence - City of Surrey and OpenStreetMap contributions under their applicable licences. See the in-app source links and data manifests.
